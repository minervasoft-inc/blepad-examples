# ESP32 BLE楽器サンプル（圧電ブザー1個）

[English README is here](README.md)

## 概要

BlePad のテンキー画面（0〜9キー）を鍵盤代わりに使って演奏できる、
ESP32 + 圧電ブザー1個だけの簡易BLE楽器サンプルです。NUS（Nordic UART Service）
互換のBLEサーバーをESP32上に実装しており、`arduino/BlePadUartTest/` と同じ
UUIDを使用しています。

## 必要なもの

- ESP32 開発ボード
- 圧電（パッシブ）ブザー 1個
  - ※内部に発振回路を持つ「アクティブブザー」ではなく、周波数を変えて音階を
    鳴らせる「パッシブブザー（圧電スピーカー）」を使用してください
- ブレッドボード・ジャンパー線
- スマートフォン（BlePad アプリ）

## 配線

| ESP32 | 圧電ブザー |
|---|---|
| GPIO25 | 端子1 |
| GND | 端子2 |

抵抗は基本的に不要です。GPIO番号はスケッチ冒頭の `BUZZER_PIN` で変更できます
（お手持ちのESP32開発ボードで使用できないピンの場合は適宜変更してください）。

## セットアップ手順

1. Arduino IDE で ESP32 ボードパッケージ（v2.0.3 以降。`tone()`/`noTone()` を使用するため）を導入する
2. ライブラリマネージャから「NimBLE-Arduino」（2.x系）をインストールする
3. [ble-buzzer.ino](ble-buzzer.ino) を開き、ESP32 に書き込む
4. シリアルモニタ（115200bps）で初期化ログを確認する

## BlePad側の操作方法

1. BlePad アプリを起動し、スキャン画面から `BlePad-ESP32-Buzzer` に接続する
2. 標準送信画面を「テンキー」に切り替える
3. 0〜9のキーを押している間、対応する音階が鳴る（離すと止まる）

### キーと音階の対応

| キー | 音階 | 周波数 |
|---|---|---|
| 0 | ド (C4) | 262 Hz |
| 1 | レ (D4) | 294 Hz |
| 2 | ミ (E4) | 330 Hz |
| 3 | ファ (F4) | 349 Hz |
| 4 | ソ (G4) | 392 Hz |
| 5 | ラ (A4) | 440 Hz |
| 6 | シ (B4) | 494 Hz |
| 7 | ド (C5) | 523 Hz |
| 8 | レ (D5) | 587 Hz |
| 9 | ミ (E5) | 659 Hz |
